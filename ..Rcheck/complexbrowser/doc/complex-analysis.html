Complex Analysis Workflow

This vignette runs protein complex analysis from R without a Shiny session. The workflow starts from QC statistics, selects a complex database, filters to one organism, scores matching complexes, and returns a display-ready result table.

library(complexbrowser)

input_file <- complexbrowser::complexbrowser_extdata_path("examples", "myo.csv")
input <- read.csv(input_file, check.names = FALSE)

qc <- complexbrowser_run_qc(
  data = input,
  no_cond = 6,
  no_rep = 3,
  log2 = FALSE,
  grouped = TRUE,
  q_values = TRUE,
  normalization = NULL,
  design = "unpaired"
)

Run complex analysis with the bundled CORUM database. The organism value must match the organism labels used in the selected database.

complex <- complexbrowser_run_complex_analysis(
  stats = qc$stats,
  database = "CORUM",
  organism = "Human",
  no_cond = 6,
  no_rep = 3,
  database_name = "CORUM"
)

ComplexBrowser can also generate a short condition-specific summary from the scored database. Lower noise_threshold values make this summary more selective.

summary_text <- complexbrowser_complex_summary(
  complex$scored_database,
  no_cond = 6,
  no_rep = 3,
  condition = 2,
  noise_threshold = 0.5
)

cat(summary_text)
#> We have found 2420 protein complexes in your dataset and 729 among them with at least 3 quantified subunits. In condition 2 the most upragulated protein complex in is Propionyl-CoA carboxylase with a fold change of 17.497, 2 quantified subunits and noise level of 0.207. The most downregulated protein complex is COG1-COG8-COG2-COG3-COG4 subcomplex with a fold change of -4.323, 4 quantified subunits and noise level of 0.46.

Write the complex table when using the result in a command-line or pipeline workflow.

complexbrowser_write_complex_table(
  complex$display_table,
  file = "myo-corum-complexes.csv"
)
