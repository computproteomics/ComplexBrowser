Quality Control Workflow

This vignette runs the ComplexBrowser quality-control workflow from R without a Shiny session. The example data are bundled with the package and contain raw protein intensities for six conditions with three replicates per condition. q-value columns are already present in the input file.

library(complexbrowser)

input_file <- complexbrowser::complexbrowser_extdata_path("examples", "myo.csv")
input <- read.csv(input_file, check.names = FALSE)

Run QC with the same settings that would be selected interactively in the Shiny app. log2 = FALSE tells ComplexBrowser that the intensity values are still on the raw scale. grouped = TRUE means replicate columns are adjacent by condition. q_values = TRUE means statistical columns are read from the input instead of being calculated with LIMMA.

qc <- complexbrowser_run_qc(
  data = input,
  no_cond = 6,
  no_rep = 3,
  log2 = FALSE,
  grouped = TRUE,
  q_values = TRUE,
  normalization = NULL,
  design = "unpaired"
)

The QC report helper prepares the compact summary tables used by the Shiny report template. These tables are often enough for scripted checks or quick inspection.

report_data <- complexbrowser_prepare_qc_report_data(
  qc$stats,
  no_cond = 6,
  no_rep = 3
)
